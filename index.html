1. Introduction : pourquoi les nombres complexes ?

L'équation x² + 1 = 0 n'a aucune solution réelle : un carré est toujours positif ou nul. Pourtant, certaines équations physiques (électricité, mécanique quantique, signaux) ont besoin de solutions à cette équation.

On introduit donc un nouveau nombre, noté i, tel que :

i² = −1

L'ensemble des nombres complexes, noté ℂ, prolonge l'ensemble des réels ℝ. Tout réel est un complexe, mais l'inverse est faux.

2. Forme algébrique

Définition Un nombre complexe z s'écrit de manière unique sous la forme
z = a + ib
où a et b sont des réels. a est la partie réelle (notée Re(z)), b est la partie imaginaire (notée Im(z)).
Égalité Deux complexes sont égaux si et seulement si leurs parties réelles et imaginaires sont égales :
a + ib = a' + ib' ⟺ a = a' et b = b'

Opérations

On additionne et on multiplie comme des expressions littérales, en remplaçant i² par −1.

Exemple (2 + 3i)(1 − i) = 2 − 2i + 3i − 3i² = 2 + i + 3 = 5 + i
Inverse Pour z = a + ib ≠ 0 :
1/z = (a − ib) / (a² + b²)
Exemple 1/(1 + i) = (1 − i)/(1² + 1²) = (1 − i)/2 = ½ − ½ i

3. Conjugué d'un nombre complexe

Définition Le conjugué de z = a + ib est z̄ = a − ib.
Propriétés
z + z̄ = 2Re(z)   •   z − z̄ = 2i·Im(z)
z · z̄ = a² + b²   •   z + z' = z̄ + z̄'
z · z' = z̄ · z̄'   •   (z/z') = z̄ / z̄'
Exemple z = 3 − 2i. Alors z̄ = 3 + 2i et z·z̄ = 3² + (−2)² = 9 + 4 = 13.

4. Module et argument

Module Le module de z = a + ib est |z| = √(a² + b²). C'est la distance de l'origine au point d'affixe z.
Propriétés du module
|z·z'| = |z|·|z'|   •   |z/z'| = |z|/|z'|
|z|² = z·z̄   •   |z + z'| ≤ |z| + |z'|
Argument Pour z ≠ 0, on appelle argument de z, noté arg(z), l'angle θ tel que :
a = |z|·cos θ   et   b = |z|·sin θ
L'argument est défini modulo 2π.
Exemple z = 1 + i. |z| = √2. arg(z) = π/4 car cos(π/4) = sin(π/4) = √2/2.

5. Représentation géométrique

Dans le plan muni d'un repère orthonormé (O, u⃗, v⃗), à tout complexe z = a + ib on associe le point M(a ; b), appelé image de z. Le complexe z est alors l'affixe de M.

Interprétation géométrique
|z − z'| = distance entre les points d'affixes z et z'
arg(z − z') = angle orienté entre l'axe des réels et le vecteur AM
Exemple L'ensemble des points M d'affixe z tels que |z − 1| = 2 est le cercle de centre A(1 ; 0) et de rayon 2.

6. Forme exponentielle

Forme trigonométrique et exponentielle Pour z ≠ 0, avec r = |z| et θ = arg(z) :
z = r(cos θ + i sin θ) = r·eiθ
Formules d'Euler
cos θ = (eiθ + e−iθ)/2   •   sin θ = (eiθ − e−iθ)/(2i)
Formule de Moivre
(eiθ)n = einθ
Exemple z = 1 + i = √2·eiπ/4. Donc z⁴ = (√2)⁴·eiπ = 4·(−1) = −4.

7. Équations du second degré

Théorème Soit az² + bz + c = 0 avec a ≠ 0, à coefficients réels. On pose Δ = b² − 4ac.
  • Si Δ > 0 : deux solutions réelles (−b ± √Δ)/(2a)
  • Si Δ = 0 : une solution réelle −b/(2a)
  • Si Δ < 0 : deux solutions complexes conjuguées (−b ± i√(−Δ))/(2a)
Exemple z² + 2z + 5 = 0. Δ = 4 − 20 = −16 = 16i². Solutions : z = (−2 ± 4i)/2 = −1 ± 2i.

Exercice 1 — Calculs dans ℂ
On pose z₁ = 2 + 3i et z₂ = 1 − i.
Calculer sous forme algébrique : a) z₁ + z₂   b) z₁·z₂   c) z₁/z₂   d) |z₁|.
a) z₁ + z₂ = (2 + 3i) + (1 − i) = 3 + 2i.
b) z₁·z₂ = (2 + 3i)(1 − i) = 2 − 2i + 3i − 3i² = 2 + i + 3 = 5 + i.
c) z₁/z₂ = (2 + 3i)/(1 − i) = (2 + 3i)(1 + i)/((1 − i)(1 + i)) = (2 + 2i + 3i + 3i²)/2 = (−1 + 5i)/2 = −½ + (5/2)i.
d) |z₁| = √(2² + 3²) = √(4 + 9) = √13.
Exercice 2 — Équation du second degré
Résoudre dans ℂ l'équation : z² − 4z + 13 = 0.
Δ = b² − 4ac = (−4)² − 4×1×13 = 16 − 52 = −36.
Δ < 0, donc les solutions sont complexes conjuguées :
z = (4 ± i√36)/2 = (4 ± 6i)/2 = 2 ± 3i.
Les solutions sont z₁ = 2 + 3i et z₂ = 2 − 3i.
Exercice 3 — Forme exponentielle et puissance
On pose z = 1 + i√3.
1) Calculer le module et un argument de z.
2) Écrire z sous forme exponentielle.
3) En déduire z⁶.
1) |z| = √(1² + (√3)²) = √(1 + 3) = 2.
cos θ = 1/2 et sin θ = √3/2, donc θ = π/3 (modulo 2π).
2) z = 2·eiπ/3.
3) z⁶ = (2·eiπ/3)⁶ = 2⁶·ei·6π/3 = 64·ei2π = 64·1 = 64.
